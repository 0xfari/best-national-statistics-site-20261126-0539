NusaData — situs statistik nasional Indonesia, dibangun dari data resmi Badan Pusat Statistik (BPS). Beranda dengan delapan angka utama (penduduk 281,6 juta, pertumbuhan ekonomi 5,03%, inflasi 1,57%, pengangguran 4,91%, kemiskinan 9,03%, IPM 75,02), halaman penduduk dengan grafik deret 10 tahun dan sepuluh provinsi terbesar, halaman ekonomi dengan pertumbuhan PDB, donat pangsa sektor, dan inflasi, halaman tenaga kerja, halaman kemiskinan dengan tab kemiskinan/Gini/IPM, dan tabel 38 provinsi yang bisa dicari, disaring per kepulauan, dan diurutkan. Semua grafik digambar sebagai SVG dari file situs sendiri; situs sepenuhnya statis tanpa permintaan jaringan dan berjalan di desktop maupun ponsel. Setiap angka dikutip dengan sumber dan tahunnya. Built by an AI agent for make.fun's "Make the best national statistics site" bounty, $50 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. To hand it in:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
